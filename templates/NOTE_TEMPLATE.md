# 微信读书笔记 → ima 笔记整理模板（固定格式）

> 每次将微信读书划线/想法同步为 ima 笔记时，必须使用此模板格式。

## 笔记结构

```markdown
# 📖 《书名》读书笔记

> 📝 **简介**：{书籍简介}

## 📋 书籍信息

| 项目 | 内容 |
|------|------|
| 📕 书名 | 《书名》 |
| ✍️ 作者 | {作者} |
| 🖋️ 译者 | {译者，如有} |
| 🏷️ 分类 | {分类} |
| 🏢 出版社 | {出版社} |
| 📅 出版时间 | {YYYY-MM-DD} |
| 🔖 ISBN | {ISBN} |
| 🔗 阅读 | [打开阅读]({deepLink}) |

## 🎯 读书前 · 阅读计划

> ✍️ 阅读前填写，带着目标去读

- **阅读目的**：（为什么读这本书？想解决什么问题？）
- **预设问题**：（带着哪 2-3 个问题去读？）
- **记录方式**：微信读书划线 + 想法，同步整理至 ima

## 📖 读书时 · 划线摘录

> 📌 划线共 {N} 条 · 💭 想法 {M} 条 · 点击划线可在微信读书 App 中查看

### 📄 {章节名}

> 📌 {划线原文（可点击链接到书籍）}
> 💭 {对应的个人想法，无则省略}
> ⏱ {YYYY-MM-DD}

## 🧠 读书后 · 思考沉淀

**💡 核心观点**（基于划线内容自动提炼）：
> {基于用户全部划线提炼的核心观点}

**✍️ 我的解读**：（读完后用自己的话复述，检验是否真正理解）

**✅ 行动清单**：（书中的方法如何应用到工作/生活？列出 1-3 条可执行行动）

---

*本笔记由微信读书划线自动整理 · 格式：读书前计划 → 读书时摘录 → 读书后沉淀*
```

## 同步流程

1. **检测新增书籍**：每次同步先调 `/user/notebooks` 获取全部有笔记的书，对比已建笔记的书单（反脆弱/人民日报评论/非暴力沟通/掌控习惯），**发现新书必须为其新建笔记**（同模板），不能只更新旧书
2. **拉取数据**：每本书调 `/book/bookmarklist`（划线）+ `/review/list/mine`（想法，count=100）+ `/book/info` + `/book/chapterinfo`
3. **生成笔记**：按上文模板，章节按目录顺序、划线按 range 升序、想法去重
4. **增量更新 ima 笔记（禁止整体覆盖）**：已存在的书**只替换「读书时·划线摘录」区域**——通过 export_note_blocks 定位「读书时」标题 block 与「读书后」标题 block，删除两者之间**自动生成格式的 block**（`> 📌`划线、`> ⏱`时间戳、`> 💭`想法、`### 📄`章节标题、说明行），**以及"想法碎片"**（内容完整包含于微信读书想法文本中的块——多行想法被 ima 拆分出的续行），**保留用户手动插入的内容**（文字/图片）。删除操作超过 100 项时**循环分批**（每批≤95 个 DELETE，最后一批 DELETE+APPEND）。仅当定位失败时 fallback 全量替换。新书用 import_doc 创建到「微信读书」笔记本
5. **知识库归档**：更新/新建的笔记通过 add_knowledge 同步到个人知识库「阅读」（新书必须导入）

## 整理规则

1. **按章节分组**：划线按 `chapterUid` 分组，章节标题用 `### 📄 {章节名}`；**章节顺序必须按书籍目录顺序排列**（调用 `/book/chapterinfo` 获取完整目录，按 `chapterIdx` 升序），**禁止按划线时间顺序排列**（bookmarklist 返回顺序是按划线时间倒序，直接使用会导致新划的章节排在前面）
2. **划线排序**：**章节内的划线按 `range` 起始位置升序排列**（即文中先后顺序），禁止按划线时间排序
3. **想法完整拉取**：`/review/list/mine` 的 count **必须传 100**（传 50 会截断旧想法导致缺失，接口 totalCount 与实际返回可能不一致）
4. **想法去重**：同一 range 下内容完全相同的想法只保留一条（接口可能返回重复想法，按 range+content 去重）
2. **想法挂载**：想法（review）通过 `range` 匹配到对应划线，放在划线下方（💭）；无匹配划线的想法作为独立条目
3. **划线链接**：划线原文用 Markdown 链接包裹（链接指向书籍 deepLink，手机端可唤起微信读书 App）
4. **核心观点**：同步时基于该书全部划线内容自动提炼一段核心观点总结
5. **增量同步**：后续新增划线按章节追加到「读书时·划线摘录」对应章节下，不重复已有内容
6. **时间戳**：Unix 时间戳转为 YYYY-MM-DD 展示
7. **目标位置**：笔记放入「微信读书」笔记本（folder_id 见 skill 使用说明），每本书一篇笔记
8. **知识库归档**：笔记创建/更新后，通过 `add_knowledge`（media_type=11）导入个人知识库「阅读」（kb_id 见 skill 使用说明），保持知识库与笔记同步
