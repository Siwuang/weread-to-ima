# 配置说明

> 所有个人配置都在 `config.json` 里。**脚本不需要改，改配置就行。**

---

## 一、准备工作

### 1. 复制配置模板

```bash
cp config.example.json config.json
```

### 2. 设置环境变量（凭证不进代码库）

```bash
export WEREAD_API_KEY="你的微信读书 API Key"
export IMA_OPENAPI_CLIENTID="你的 ima clientid"
export IMA_OPENAPI_APIKEY="你的 ima apikey"
```

> ⚠️ **凭证只走环境变量**，永远不要写进 `config.json` 或提交到仓库。

---

## 二、config.json 字段说明

### `workdir`

数据与笔记的输出目录。支持相对路径（相对 config.json 所在的目录）。

```json
"workdir": "./data"
```

### `weread.books[]` — 要同步的书

| 字段 | 说明 | 必填 |
|---|---|---|
| `abbr` | 缩写，用作文件名前缀 | ✅ |
| `book_id` | 微信读书 bookId（详见下方"怎么找"） | ✅ |
| `title` | 书名（用于兜底显示） | |
| `type` | 填 `article` 表示公众号文章（无章节目录） | |
| `md_file` | 输出文件名（默认 `note_<abbr>.md`） | |

### `ima` — 目标平台

| 字段 | 说明 |
|---|---|
| `notebook_folder_id` | 笔记要放进哪个笔记本 |
| `kb_id` | 知识库 ID |
| `kb_folder_id` | 知识库里的目标文件夹 |

### `notes[]` — 笔记 ID 映射

| 字段 | 说明 |
|---|---|
| `abbr` | 对应 `weread.books` 里的 abbr |
| `note_id` | ima 笔记 ID（首次推送后获得） |
| `md_file` | 对应的 markdown 文件 |
| `name` | 显示名 |

### `core_views.json` — 每本书的"核心观点"

**这是唯一需要"人写"的内容** —— 读完后自己提炼的摘要。

- key = bookId
- value = 一段话摘要
- **留空也没关系**，笔记里会保留占位符

---

## 三、bookId 怎么找

在微信读书网页端打开一本书，URL 里的数字就是：

```
https://weread.qq.com/web/bookDetail/xxxxxxxxxxxxxxxxxxx
                                    ↑ 或 URL 参数 bookId=xxxxx
```

公众号文章则是 `MP_WXS_xxxxxxxxx` 形式。

## 四、运行

```bash
# ① 拉取数据（可指定书名缩写）
python3 scripts/fetch_weread.py
python3 scripts/fetch_weread.py fq nwe      # 只拉某几本

# ② 生成笔记（读 config.json 里的 books）
python3 scripts/gen_notes.py

# ③ 增量同步到 ima（自动跳过没变化的书）
python3 scripts/update_notes.py
python3 scripts/update_notes.py --force     # 强制全量
```

## 五、常见问题

**Q：报"未找到配置文件"？**
A：先 `cp config.example.json config.json`。

**Q：报缺环境变量？**
A：检查 `export` 是否生效（新开终端要重设，想持久化就写进系统环境变量）。

**Q：第一本书同步后，note_id 从哪来？**
A：首次用 `push_note` 创建笔记，把返回的 `note_id` 填进 `config.json` 的 `notes[]`。

**Q：数据存在哪？**
A：`workdir` 里 —— `weread_<abbr>_*.json` 是原始数据，`note_<abbr>.md` 是生成的笔记。

**Q：想只给某本书重跑？**
A：`python3 scripts/fetch_weread.py fq && python3 scripts/gen_notes.py`
